# akvizice-prodejny

Jednou měsíčně připraví balík prodejen v Česku pro Akviziční mapu (výřez mapy Česka od Geofabriku, data OpenStreetMap).

- Spouští se samo 2. den v měsíci, ručně: **Actions → Prodejny z mapy → Run workflow**.
- Výsledek: **Releases → Prodejny z mapy** (`prodejny.zip`, `meta.json`). Aplikace si ho stahuje sama.
- Které druhy prodejen se berou: `typy.txt`.
